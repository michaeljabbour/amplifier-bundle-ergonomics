# UX Ergonomist capability

Delegate to `ux-ergonomist:ux-ergonomist` when a task requires evidence-led UX, human factors, usability, accessibility, cognitive ergonomics, information architecture, interaction design, user research, or human-AI interaction judgment.

Use it before visual design when the product problem, user task, risk, or evaluation standard is unclear. Use it after design when a flow, prototype, or implementation needs a rigorous review. It complements visual design specialists; it does not replace art direction or component production.
