# Temporal interaction

Time is part of the interface.

Evaluate:

- response latency and whether feedback matches actual progress
- streaming output versus stable reviewable output
- timeouts, expiry, and recoverability
- notification timing, urgency, and interruption cost
- pause, resume, cancellation, and checkpoint behavior
- long-running task visibility and background execution
- false confidence caused by instant answers
- false thoughtfulness inferred from deliberate delay
- handoff timing and stale state
- resumption cues after interruption

Measure perceived quality, behavioral performance, workload, and error detection separately. Do not infer one from another.
